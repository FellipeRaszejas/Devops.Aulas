# Semana 02 — Perguntas de Fixação

1. Quais são os 4 objetos internos do Git e o que cada um armazena?
2. Por que o Git é descrito como um grafo (DAG) e não como uma lista de diffs?
3. Complete a tabela de memória: de onde nasce e para onde vai cada uma das 5 branches do GitFlow (`main`, `develop`, `feature/*`, `release/*`, `hotfix/*`)?
4. Escreva um exemplo de mensagem de commit no padrão Conventional Commits para: (a) uma nova funcionalidade, (b) uma correção de bug, (c) uma breaking change.
5. Qual a diferença visual/prática entre um merge normal (fast-forward) e um `git merge --no-ff`?
6. Por que o GitFlow recomenda `--no-ff` em vez de deixar o Git decidir automaticamente?
7. Em que situação você usaria `git rebase` em vez de `merge`, e qual o risco de reescrever histórico já compartilhado?
