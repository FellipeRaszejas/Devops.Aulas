# Semana 04 — Perguntas de Fixação

1. O que é um repositório aninhado e como você verifica, antes de clonar, se está numa pasta segura?
2. Descreva a sequência completa de comandos, do clone até o push final, para desenvolver uma feature isolada.
3. Explique com a metáfora da "fita cassete" (ou outra sua) a diferença entre merge fast-forward e `--no-ff`.
4. Por que o Git rejeita um push com `non-fast-forward` e qual comando resolve isso?
5. O que significam as três partes de um conflito de merge (`<<<<<<< HEAD`, `=======`, `>>>>>>> hash`)?
6. Depois de integrar uma feature com sucesso na `develop`, quais dois comandos você usaria para limpar a branch (local e remota)?
7. Para que serve o comando `git log --oneline --graph --decorate --all`?
